# Fixed-shape native verifier constraint inventory

From this directory, run:

    PYTHONDONTWRITEBYTECODE=1 python full_count.py large_2p20_model.json
    PYTHONDONTWRITEBYTECODE=1 python full_count.py integrated_fixture.json
    PYTHONDONTWRITEBYTECODE=1 python control_tests.py
    sha256sum -c verifier_census.sha256

The count covers the initial Hachi trace, Eq. 20 and Fig. 7, the same-commitment successor trace and Greyhound, one real LaBRADOR round, and the resulting folded terminal. It includes canonical wire range checks, transcript hashing, fixed-budget coin parsing and selection, signed spectral challenge bounds, and both exact integer norm comparisons. It does not estimate runtime or a proof system for this circuit. Source fixture tests exercise the protocol; this tool counts a specified fixed mixed-field circuit by formulas and symbolic templates, not by compiling the Rust program.

**Main profile (analytical only).** Polynomial: 2^20 base coefficients and a private E=Fp4 evaluation point/value, with original commitment and keys public. Hachi: d1024, 64×64 split, ranks 1, base16, challenge weight16 and folded depth4, generic no-peeling trace. Eq.20 has 3072 short ring words, 40 quotient words, and two 22-round sumchecks. Greyhound: d64, 128×2048 words, ranks1, depth8/input_depth1, challenge weight16, produces 4096 short relation words and 5 ring rows. This schedule is **not** claimed secure, parameter-calibrated, integrated at this size or recommended for production.

## Counting rules and controls

- Fp multiplication is one product constraint with affine-form inputs. Fixed-field additions, sign permutations, public coefficients, cross terms in fixed-radix decompositions, and schoolbook convolution output sums are inlined, not separate rows. Fp affine is a materialization or an equality row (such as output checks, fixed matrix evaluations deliberately materialized here, and codec reconstructions). A general Fp4 product uses at most nine Fp products via two levels of Karatsuba. A general R64 product is lowered using 4096 Fp products; an R64 square is 2080 using symmetry. Ring entries are informational subcounts, not additive.
- F2 AND, XOR and equality are counted separately. NOT uses a free wire polarity. Keccak-f[1600] charges all 24 rounds (38,400 AND, 115,200 XOR), plus frontend absorption XORs. Nimue's overwrite absorption has no additional XOR, and one real round has no chaining hash after its final proof bytes. Initial dynamic chain, hexadecimal encoding, and IOPattern tag are included. The verifier-fixed CRS digest is precomputed.
- Each coefficient conversion records a Boolean↔Fp lift, not a claim that the lift has zero cost or can be summed as one row with a base field. One canonical private coefficient bridge also charges a 31-AND range predicate, one F2 check, and one Fp reconstruction. For the front transcript we deliberately reserve enough bridges to cover even its entire byte stream as field words. Non-field slots use dummy gates, and no hash bytes are required to be canonical field words. Frontend selection/routing and input XOR bounds are intentionally conservative.
- Both squared norms are ordinary integers, not modular checks. The centered coefficient square and integer sum/comparison are explicit binary gate templates with no wrap. The public integral cutoff is the floor of the parameter's static binary64 bound. The terminal has six or fifteen ring equalities for these ranks, plus its integer norm. The terminal evaluator's dense generic loops can be transformed exactly into sparse native equations because it checks the same decomposed z,t,g,h and fixed zero positions. Only the folded terminal is decoded, not the original Greyhound witness.
- LAB uniform-field selection checks all six candidates and consumes the first acceptable word. For every exact short fold challenge, we evaluate all 128 candidates with the actual 128 source cosine constants. Per candidate: fixed-modulus long division, Fisher–Yates swaps, sign FIFO, 32 checked spectral norms; then select the same first accepted candidate. Keccak stream length per returned short challenge is 65,280 bytes. The arithmetic control tests compare modular division, centered squares, and the signed sampler/filter math with independent integer calculations.
- Thus the totals are a constructive conservative component-wise upper bound in a specified native mixed gate model, not an exact minimum, independent single-field R1CS size, library runtime/circuit instrumentation, or security estimate. For a real wrapper choose an outer lattice modulus and implementation of all bit↔Fp lifts, nonnative reductions and range constraints before reporting its one-field circuit size or proof length.
